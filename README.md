# Conceptos Uniformes - Landing page

Proyecto escolar de una landing page estática para un negocio de uniformes corporativos. Su objetivo es presentar la propuesta de valor, mostrar un catálogo breve y captar solicitudes de cotización.

## Demo

Abre `dist/index.html` en un navegador o utiliza la URL pública incluida en la entrega.

## Tecnologías

- HTML5 semántico
- CSS3 con Flexbox y CSS Grid
- Responsive Web Design mediante media queries
- JavaScript para menú móvil y validación de formularios
- Git para control de versiones

## Secciones

1. Header con logotipo y navegación.
2. Jumbotron con mensaje del negocio y captura de correo.
3. Catálogo de líneas corporativa, industrial y hospitalidad.
4. Ventajas y proceso de trabajo.
5. Presentación de la empresa.
6. Registro para solicitar una cotización.
7. Footer con enlaces, contacto y redes sociales.

## Prototipo

El prototipo de baja fidelidad está disponible en [`docs/prototipo.svg`](docs/prototipo.svg). Muestra la distribución planeada antes del desarrollo.

## Cómo ejecutar el proyecto

No requiere instalación ni dependencias. Descarga el repositorio y abre `dist/index.html` en cualquier navegador moderno.
