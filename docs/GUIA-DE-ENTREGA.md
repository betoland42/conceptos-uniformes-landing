# Guía de entrega

## Evidencias sugeridas

1. Captura del prototipo de baja fidelidad.
2. Captura de la landing en escritorio.
3. Captura de la landing en vista móvil.
4. Enlace del repositorio público de GitHub.
5. Enlace de la página desplegada.
6. Captura del historial donde se observen al menos cinco commits.

## Publicar el repositorio en GitHub

1. Crea un repositorio vacío llamado `conceptos-uniformes-landing`.
2. En la carpeta del proyecto agrega el repositorio como remoto.
3. Sube la rama `main`.
4. En GitHub abre **Settings > Pages**.
5. Selecciona la rama `main` y la carpeta `/dist` si GitHub la ofrece. Si Pages solo permite la raíz, mueve el contenido de `dist` a la raíz antes de publicar.

## Lista final

- Comprueba que la URL abra sin iniciar sesión.
- Prueba los enlaces del menú y ambos formularios.
- Reduce el ancho del navegador para mostrar el menú móvil.
- Entrega antes de la fecha límite indicada por tu profesor.
